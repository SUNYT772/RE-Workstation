# 运行时字符串与密码数据流

## 输入与上下文

字符串来源、字节数组、编码、调用上下文与对象生命周期。

## 方法与判断

原观察点包括 StringBuilder.toString、String(byte[])、URL构造、Base64编解码、MessageDigest、Cipher 与 SharedPreferences字符串写入。串联构造→编码→摘要/加密→发送/存储的链，区分明文、密文、密钥材料、签名与普通字符串；记录长度与字节编码，空值或不可读地址独立表示。

## 原模板实际记录与边界

| 观察项 | 实际记录内容 | 过滤、返回与局限 |
| --- | --- | --- |
| 共用日志入口 | 标签 tag 与值共同组成去重键 | 同标签、同值只展示一次；相同值在不同标签下仍可分别出现。去重状态先于长度筛选登记，不能把未展示等同于未捕获。 |
| 字符串展示窗口 | 仅展示长度严格大于 2、严格小于 5000 的值，即 2 < 长度 < 5000 | 长度为 2 或 5000 的边界值也不展示；这是共用日志入口的筛选，不是所有观察点统一截断到 5000 字符。 |
| StringBuilder 与字节构造字符串 | 前者记录构造结果；后者记录字节转换后的字符串，显式字符集重载的标签含字符集名称 | 均经过共用日志入口，受标签与值去重、长度窗口影响；日志没有独立保存全部原始字节。 |
| URL 构造 | 以 http 开头、且不含 fonts. 或 android. 的 URL 文本 | 直接输出，未使用共用日志入口；此处不能套用上述去重和长度窗口，也不能把筛选掉的 URL 视作没有发生。 |
| Base64 decode | 将编码输入的字节数组转为字符串后记录 | 实际记录的是编码输入，不是解码后的返回字节；原解码结果仍返回给原流程。此字符串转换未显式指定字符集。 |
| Base64 encode | 编码后的字符串结果 | 经共用日志入口记录，并将原编码结果返回给原流程；日志没有另行保存编码前字节。 |
| MessageDigest | 标签中含输入字节转换成的字符串，值为摘要的十六进制表示 | 摘要值受共用日志入口筛选；输入字符串位于标签，不能据该筛选推断输入本身也在同一长度窗口。原摘要字节返回给原流程。 |
| Cipher | 算法名称，以及输入和输出字节的十六进制摘要 | 直接输出，未经过共用日志入口；返回原变换结果。算法名称不等于完整保存了模式、密钥、IV 或算法参数。 |
| 十六进制表示 | 每份字节数组最多展示前 64 字节，即最多 128 个十六进制字符；空引用显示为 (null) | 超过 64 字节的尾部不在记录中；原帮助函数未另报完整字节数，短文本不能独自证明原数据也短。 |
| SharedPreferences 字符串写入 | 标签含存储键名，值为拟写入字符串 | 经共用日志入口记录，原写入过程及其返回结果另行保留；日志本身不证明后续持久化已完成。 |

共用日志入口的过滤、字节表示的截短与具体观察点是否覆盖是不同边界。未见某条记录可能来自未命中、重复值、长度筛选或观察点不可用；原模板对多处异常未输出细节，不能仅凭末尾启用提示认定全部观察点已生效。

## 建议的结果结构

数据流节点、输入输出摘要、算法/模式、时间、调用链、存储键名及脱敏证据。时间、完整调用链、原始总长度及截短标记等可作为补充记录字段，原模板并未在每条日志中自动提供；输入、输出与返回值按上表的实际记录范围分别说明。
