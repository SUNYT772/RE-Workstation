# API 状态与签名结构

## 输入与上下文

base URL、应用标识、参数、会话、设备与账户状态。

## 方法与判断

原独立模板将参与参数按键排序后以 & 拼接，再附 __appId 与 __key 后求MD5；排除字段显式记录。心跳包含 lang、deviceId、token、_openid、_account_id，签名计算一次，区分普通参数与凭据状态。独立模板以表单表达，手册内示例使用JSON并有毫秒时间戳，二者不是同一个协议。类注释提到自动重试但实现没有，不将其列为已有能力。
