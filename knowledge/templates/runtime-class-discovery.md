# 运行时类与加载状态

## 输入与上下文

包名前缀、关键词、当前类加载器与目标触发路径。

## 方法与判断

按包过滤和按关键词分组是两个视图；关键词可能重叠，分组计数不等于唯一类数。已加载类集合随运行状态变化，未发现类不代表样本不存在该逻辑。

## 原模板实际记录与计数

| 记录层次 | 实际含义 | 展示与计数边界 |
| --- | --- | --- |
| 包名前缀 | 非空时按类名的原始前缀筛选；空前缀不作包过滤 | 前缀比较与关键词匹配是两个条件，原前缀比较没有转成小写。 |
| 关键词匹配 | 类名先转成小写，再匹配关键词；至少命中一个词的条目进入 found | 一条记录保存类名及全部命中关键词；没有额外的类名去重步骤。 |
| 每关键词完整计数 | 该关键词分组中实际收集的条目数 | 分组标题所示总数取自完整分组，不是可见的展示行数。 |
| 每关键词展示窗口 | 每个关键词最多展示前 20 条类名 | 超过 20 条时另外报告省略数，省略数为该组完整计数减去 20；省略不代表未收集或未命中。 |
| 全部命中条目数 | 完整 found 的条目总数 | 不受每关键词 20 条的展示上限影响，也不按一个类命中了几个词而重复累计；这不等于原模板额外实现了类名去重。 |
| 关键词组数与分组行数 | 组数是存在命中结果的关键词数量；分组按关键词名称排序展示 | 同一类可出现在多个关键词组，所有分组计数之和或可见行数之和都不能直接当作唯一类数。 |

报告可同时区分命中条目总数、各组完整计数、各组展示数与省略数。仅有前 20 条展示窗口时，无法由可见类名恢复该组的完整集合。

## 建议的结果结构

类名、加载器、归属包、命中关键词、首次出现的运行阶段与关联方法。原模板实际收集的是类名及命中关键词，并输出上述计数；加载器、首次出现阶段和关联方法属于建议补充的上下文，不能误写成原日志已记录的字段。
