# AI Agent 的安全边界与评估证据

来源：skills/llm-security/references/agent-security-testing.md

## Agent 与普通 LLM 的差异

规划、外部动作、跨会话记忆、Agent 通信和后台执行使影响从回答可信度扩展到控制权。风险模型需要把身份、目的、参数、数据、持久状态与外部副作用联系起来；原七阶段改为可独立比较的七个边界。

## 1. 攻击面枚举

能力清单表达名称、参数与权限；用户输入、模型、动作接口和外部系统分别属于不同信任域。一个能力的输出可能成为另一个能力的参数。人工确认触发条件、记忆/向量库内容、检索与更新时机，决定数据何时有机会影响控制流。

## 2. 动作组合：ASI02 / ASI05

原新闻场景包含检索输出、跨用户资产数据、报告与外部发送。关键失败是检索内容被当成指令，后续参数范围扩大并向非预期接收方暴露。观察项包括每个中间输入的来源、身份范围、参数变化、动作次序和最终外部影响。原嵌入指令、参数注入和两项以上能力组合被保留为信任关系，不复制攻击语句或调用代码。

## 3. 人在回路：ASI09

紧急感、CEO/CISO 等权威叙述、重复正常请求造成的疲劳、用 RFC 等技术细节包装操作，可能影响人工判断或确认语义。原“先二十次正常、第二十一次异常”是疲劳样例，非固定流程。证据需要说明确认者看见什么、批准对象和实际动作是否一致、原确认条件是否真的满足；单纯出现批准文本并不证明真实授权。

## 4. 记忆与上下文：ASI06

源案例中财报 PDF 将高风险客户误标为 VIP/低风险，数周后贷款审批取用该记忆，导致业务决策污染。问题跨越文档数据、长期状态与后续用途，不只是单轮输出。多轮矛盾信息、记忆替换规则、检索时权限复核及 PoisonedRAG 的文档排名，是原观察内容。客户 ID 已角色化；报告保留时间线和误判链。

## 5. 系统提示词：LLM07

源五个层次包含直接复述、翻译、JSON 配置、限制措辞和生产调试包装，表达形式变化对保密属性的影响。Canary token 是唯一内容标记；出现可支持泄漏判断，未出现不排除部分泄漏。保留泄漏范围、输出上下文和标记角色，不复制提取话术。

## 6. 输出处理链

| 下游 | 数据变代码/权限的边界 | 原文控制目标 |
|---|---|---|
| HTML / JS | 生成内容进入 DOM 执行语义 | 实体编码及适配上下文的处理 |
| SQL | 文本拼接成查询语法 | 参数化 |
| Shell | 文本进入命令解释 | 参数边界与避免不必要解释 |
| HTTP | 模型生成目标影响服务端访问 | 目的地与权限范围 |
| 邮件 | 正文/字段被解释为邮件头 | 头字段与换行注入防护 |

原 XSS、SQL 删除、Shell 外传、内部管理 URL 与 Bcc 载荷均改为机制说明。记录下游解析器、字段和实际影响，不把模型输出当可信代码。

## 7. 级联故障与韧性：ASI08 / ASI10

单点记忆可影响所有依赖该记忆的决策；某一能力越权可能扩大资源面；新 Agent 实例、无用户交互的后台持续性、紧急停止能力属于生命周期边界。观察的是故障传播范围、创建者身份、持久状态、回滚与停止后的实际状态，不规定自我复制或后台执行步骤。

## AgentThreatBench 双指标

源材料以 Utility Metric 表达合法任务完成，以 Security Metric 表达抵抗目标劫持；两者同时满足才说明任务有效且边界成立。原 1.0 阈值和“多数前沿模型失败”是特定基准语境，未在此进行最新核验。过度拒绝与被劫持应分别记录，不能用单一安全得分掩盖正常任务失效。

## 证据结构与来源

保留合法目标、输入来源、信任边界、身份/权限、记忆时间线、人工确认、外部结果、效用与安全两项结果。来源背景为 OWASP ASI 2026、UK AISI AgentThreatBench、PoisonedRAG；不形成工具依赖。
