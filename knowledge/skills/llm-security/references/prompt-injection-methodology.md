# Prompt 注入的机制与观察方法

来源：skills/llm-security/references/prompt-injection-methodology.md

## 注入分类

### Direct Injection

输入者在直接交互中试图把自然语言当作新的控制规则，覆盖原任务或隐藏指令的边界。

### Indirect Injection

网页、邮件、PDF、数据库等本来是业务数据，其内容被误提升为控制指令。摄取、检索、摘要与后续动作之间的信任转换是核心；不是所有恶意文本都会被执行，证据需要看到目标或参数实际改变。

## 五种递进复杂度

### Level 1：直接覆盖

源例包含忽略先前指令、开发模式、强制固定结尾与系统覆盖宣称。它们共同伪造更高优先级或改变输出目标。本页保留模式和判据，不复制原话术。

### Level 2：角色扮演与越狱

DAN、影视角色、学术/模拟包装的共同机制是用叙事重新定义允许的行为。评估区别在于模型是否继续完成合法任务、是否把叙事当成真实权限，而不只看是否承接了角色名称。

### Level 3：编码与表示

Base64、ROT13、Hex、Unicode 同形字、零宽字符及多语言改变表示层，可能使关键词/精确匹配与语义解释不一致。Cyrillic 与 Latin 外观相近而编码不同，零宽字符改变字节而不显著改变视觉。原希腊字母示例的具体字形映射不作字符学事实扩展。韩语、日语、阿拉伯语是源文多语言范围，未保留编码后的攻击串。

### Level 4：多轮渐进

原五轮从限制主题、限制用词、具体句子扩展到相邻上下句，说明每次片段看似有限但累计泄漏可能扩大。证据应按轮次累计已暴露内容，区分单轮与会话整体边界，不复制提取问题模板。

### Level 5：RAG 与隐藏内容

隐藏 HTML、白字/零字号内容在视觉上不突出，但文本提取可能读到。伪装为系统身份或把后续消息导向外部接收者，是源例的控制目标。知识页保留视觉/提取文本差异和指令来源问题，移除 HTML 载荷、外部地址与转发语句。

## 测试能力的输入输出

原 garak 代表探针类别与结果，PyRIT 代表目标、多轮对话与评分分离，promptfoo 代表提示版本、模型配置、注入/越狱/编码/多语言四类回归标签。工具名只保留历史能力概念，不规定平台、安装、调用或配置代码。

## 规避类别的知识对照

| 类别 | 不一致的边界 | 原观察目标 |
|---|---|---|
| 编码 | 字节表示与解码后语义 | 关键词过滤与实际解释差异 |
| 同形字 | 视觉字符与码点 | 精确匹配盲区 |
| 零宽字符 | 可见文本与字节序列 | 模式匹配差异 |
| 多语言 | 单语规则与跨语语义 | 不同语言下的边界一致性 |
| 角色叙事 | 叙事身份与真实权限 | 权限是否被叙述改变 |
| 多轮 | 单条判断与累计上下文 | 片段累积的目标变化 |
| 对抗后缀 | 优化 token 与模型行为 | 原 GCG 类别的模型相关性 |

## 根本挑战与证据

同一自然语言通道承载指令和数据，使来源边界容易混淆。原文的分层目标为提高区分、可检测性和影响控制；本页不承诺某种提示能完全防御。报告包含来源、可见/提取文本、原目标、实际变化、累计泄漏、权限/外部影响及合法任务是否完成。
