# LLM 与 AI Agent 安全知识

来源：skills/llm-security/SKILL.md

## 适用场景

ChatBot、RAG、代码助手、具备外部能力/记忆/通信的 Agent、模型供应链与 AI 系统评估。原材料覆盖 OWASP LLM Top 10 v2.0 与 ASI 2026；名称和版本保留为来源语境。本页按信任边界组织问题，不规定联网、工具、安装或固定阶段。

## AI 攻击面映射

聊天、上传文件、API 参数和邮件处理是输入入口；用户输入、检索上下文、动作参数与输出目标形成数据流。动作能力包括邮件、数据库、删除和系统执行等类别，关注其参数范围与权限。错误消息、翻译/结构化输出中的内部信息和审批条件，是原文的提示泄漏与人工确认观察面。

## Prompt 注入：LLM01 / ASI01

直接覆盖、角色扮演、编码/同形字/零宽字符、多轮渐进、外部内容中的隐藏指令，是五类不同的指令来源混淆。网页/PDF/邮件等业务数据如果被提升为行为规则，会使原任务目标发生改变。本页不复制源提示词、隐藏 HTML 或转发载荷；细分机制保留在 Prompt 专页。

## 动作组合滥用：ASI02 / ASI03 / ASI05

单个能力合法，不代表其组合和参数合法。原例从新闻检索经跨用户资产查询、报告生成到外部邮件，说明低信任数据可能影响后续身份范围和接收方。审批中的紧急感、权威叙述与系统参数中的代码语义是独立边界；实际权限范围、参数来源与最终外部影响才是证据。

## 记忆与上下文投毒：ASI06

知识库文档和多轮对话可把错误事实持续写入记忆，后续检索可能再次使用。权限检查不仅涉及存储，也涉及检索时的主体与用途。原 PoisonedRAG 的“百万语料中五篇、约九成操控”是特定研究背景的源描述，不作为通用成功率。保留文档来源、检索排名、记忆版本、时间和受影响决策的对应关系。

## 输出安全：LLM05

浏览器/DOM、数据库、系统执行和 API 各自解释不同语法。生成文本进入 HTML、SQL、Shell 或 URL 时，文本可信度与下游代码/权限边界不同。输出编码、参数化查询、结构化参数、目标范围与资源授权是原文的控制目标；不能因为文本来自模型便赋予执行可信度。

## 系统提示词泄漏：LLM07

原文的复述、翻译、JSON 配置和多轮上下文提取，说明格式变化不应改变内部信息的保密属性。Canary token 是唯一标识的观察哨，输出中出现它可支持特定隐藏内容泄漏判断；没有出现并不能证明没有其他泄漏。记录输出片段时保留标识角色，不复制真实秘密。

## 能力类别与报告结构

历史 garak 代表探针集合，PyRIT 代表多轮与评分，promptfoo 代表类别化回归，promptmap2 代表双模型推理，AgentThreatBench 代表任务效用/安全双维度评估。它们仅为背景概念。

报告包含输入来源与信任级、数据流和权限、合法任务目标、目标偏移、参数/记忆/输出的实际变化、人工确认状态、合法任务效用、安全结果和回归证据。详细风险分类、Prompt 机制、Agent 边界和工作流失效知识分别在本模块细分页中保留。
