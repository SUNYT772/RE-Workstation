# 浏览器与桌面交互：状态、字段与故障定位

来源：skills/browser-automation/references/playwright-cheatsheet.md

## 主题与范围

原 Playwright/agent-browser/OpenReverse 速查转为交互语义、状态证据、选择器知识与诊断表。原 Node.js、PowerShell 和 shell 模板不作为可执行内容复制。

## 知识正文

### 导航与生命周期

页面导航、加载状态和会话结束分别影响当前文档、后续事件及资源状态。源文将未结束会话与进程泄漏相联系；没有响应需要同时考虑遗留会话与实际页面/进程状态，不能直接把原因定为泄漏。

### 页面快照

完整无障碍树提供上下文，交互元素子集减少无关信息。@e1/@e2 这样的引用依赖生成该引用的快照；刷新后身份与编号可能改变。完整树和子集不是两份完全等价的证据，报告应注明范围。

### 元素交互

| 语义 | 观察重点 |
|---|---|
| 点击 | 实际目标及点击后的状态 |
| fill / 文本替换 | 文本框最终值与相关事件 |
| type / 逐字符输入 | JS 输入监听对事件序列的依赖 |
| Enter、Tab、Escape | 提交、焦点变化、关闭等实际效果，不能只凭按键名判断 |
| 上下滚动 | 可视区域、滚动容器及坐标上下文 |

源示例的 500/300 像素只是滚动距离样例，不构成固定操作。用户名/口令示例不作为知识值保留。

### 信息获取

元素文本说明控件呈现；页面标题说明文档状态；当前 URL 说明导航位置。三者可能变化不同步，也不足以单独证明服务端业务成功。

### 等待策略与断言

元素出现、元素 visible、固定 2000 ms、networkidle、DOMContentLoaded、导航完成和目标响应分别表达不同条件。原固定时长只是示例。等待条件需与要证明的结果一致：目标响应的 status/JSON 是网络证据，导航是页面证据，错误元素 visible 是状态证据。

原并发等待模板的技术重点是：观察窗口应覆盖触发动作，避免动作已经结束才关注其响应；不保留 Promise/API 调用代码，也不指定固定等待顺序。

### 自动化登录的观察模型

登录页、用户名/口令控件、提交控件、后续网络和跳转 URL 构成关联对象。源例使用 URL 判断进入后台，本文保留为导航线索；业务身份是否成立仍需页面/服务端结果。不要把原演示账户写成真实凭据。

### 输入反射与 XSS 观察

输入点、提交事件、输出位置、编码方式、页面是否将输入当作文本或可执行结构，以及运行时/网络结果，是原注入例承载的技术目标。快照只说明呈现结构，不自动证明脚本实际执行；不复制原 script 字符串或其他攻击载荷。

### 表单批量样例的知识含义

原多样例循环意在比较同一输入点对不同输入类别的处理，包括查询表达式、HTML 事件结构和模板表达式。知识页只保留类别、输入到输出的对应、请求/响应与错误证据；不保留具体 payload、枚举循环或提交命令。不同样例之间页面/会话状态是否相同关系到结果可比性。

### Cookie 与 LocalStorage

Cookie 由浏览器上下文持有，localStorage 与页面来源相关；两个位置不能相互替代。原文的 CLI 能力与脚本模式可见性不同，是历史实现差异，不作为当前固定能力判断。报告记录来源、会话上下文、字段/键、生命周期和敏感性，不保存真实会话值。

### 截图取证

截图需要页面身份、加载状态、时间和范围。fullPage 表达全页面，视口截图只覆盖当前可见区；截图可见文本不等于 DOM 全部内容。源文提醒截图能力可能随历史版本不同，不要求某个 CLI 支持。

### 浏览器基础配置的知识含义

headless 表示是否具有可见界面；proxy 表示请求路径；userAgent 表示服务器及页面收到的身份信息；ignoreHTTPSErrors 表示证书错误是否影响页面加载。忽略证书错误后的成功不能证明原证书可信，这种观察条件应显式记载。浏览器、context 与 page 是不同会话层；不得将某页状态自动归到所有上下文。

### 常用选择器

| 类型 | 原文形式与信息 |
|---|---|
| CSS | #login-btn 表示 id；input[name="username"] 表示元素及属性 |
| 文本 | text=Submit 或按钮所含文本 Login 表示可见文本线索 |
| XPath | button 与 type="submit" 条件表达结构/属性关系 |
| 组合 | form 范围内的 input[type="submit"] 表示父范围约束 |

这些是选择器语法知识，不附点击或填表调用。文本、属性与 DOM 关系变化会影响匹配；选择器命中不等于唯一或正确业务目标。

### 网络拦截与状态变化

路径匹配范围（原示意 **/api/**）、请求 URL、请求头、响应状态与 JSON 字段属于不同对象。原例改变自定义 X-Admin 头或 JSON 的 role 字段，表达“客户端可见材料被改变”，不证明真实服务端授权改变；本文保留字段类别与前后差异的报告对象，不复制篡改调用或具体提权值。

原转发/获取真实响应/以新内容呈现的模板，核心是区分原始响应与人为构造结果。观察结论应记录哪一层发生变化及哪些证据来自原始流量。

### 桌面模式选择

UIA 提供结构化 Windows 控件，CUA 提供视觉与输入上下文。模式描述可用证据，不要求 agent 依赖 OpenReverse；原命令前缀是运行接口，已移除。

### UIA：结构化控件

窗口树、Button/Edit 等角色、控件名称、文件路径文本框、File > Open 菜单层次、输出控件文本，分别说明应用状态及可寻址目标。控件有同名情况时，窗口和父层次是重要上下文；源代码中的可执行文件路径不是知识依赖。

### CUA：视觉与键盘

截图、坐标、单击/双击、输入文本与快捷键体现视觉方式的观察条件。原文例中 Ctrl+G 表示地址定位，F5 表示 IDA 反编译，F9 表示 x64dbg 运行；快捷键受应用及焦点影响，知识记录以实际状态为准，不写自动调用。

### 桌面网络观察

代理与本地抓取范围、目标进程过滤、已捕获请求列表、HAR 导出和观察窗口结束分别描述证据范围与格式。HAR 是网络证据格式，不说明捕获范围必然完整；过滤 target.exe 也需要进程身份对应。原代理端口 8888 是配置样例，不要求启动服务。

### IDA 批量样本的证据关联

每个样本的打开文件状态、数据库、自动分析完成信号（源例观察标题栏）、函数结果及数据库切换，决定结果是否归属正确样本。Ctrl+O/Ctrl+W 是源例的历史快捷键；模板中的外部结果提取不复制为工具调用。GUI 函数清单和网络事件 Lumina 等属不同证据。

### x64dbg 断点与数据采集

目标文件、地址、断点、运行/暂停、寄存器/内存与截图共同说明调试状态。源 F3、Ctrl+G、F2、F9 表示文件、地址、断点和运行等交互意图；0x401000 是演示地址，不能移用为真实断点。观察点必须归属到当前目标和会话。

### 常见问题与定位

| 问题 | 原文候选原因 | 对应知识判据 |
|---|---|---|
| 浏览器无响应 | 遗留进程/会话 | 实际进程及会话生命周期，不能只凭无响应定因 |
| 元素引用失效 | 页面刷新 | 引用所属快照与当前文档是否一致 |
| 文本显示但行为无效 | JS 监听输入事件 | 替换文本与逐字符输入事件语义差异 |
| HTTPS 错误 | 自签名或信任问题 | 证书错误与页面证据；忽略后需标记观察条件变化 |
| 页面加载超时 | 网络慢、资源多、等待条件过强 | 文档/网络/目标元素分别是否就绪 |
| UIA 无控件 | 自绘或结构树缺失 | UIA 覆盖面与视觉证据 |
| CUA 点击偏移 | 分辨率/DPI/窗口变化 | 截图、坐标系和实际布局 |
