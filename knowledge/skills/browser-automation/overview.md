# 浏览器与 Windows 桌面：状态、交互和证据

来源：skills/browser-automation/SKILL.md

## 主题与范围

浏览器范围包括页面导航、点击、文本、表单、采集、截图、登录、验证码页面状态与批量表单结果。原文中的安全测试页面交互保留为输入到页面呈现/网络请求的观察，不保留攻击字符串。

Windows 桌面范围包括 IDA/x64dbg/Wireshark 等 GUI、结构化 Windows UI Automation（UIA）、视觉交互（CUA）、桌面网络观察及黑盒软件状态。页面中的浏览器对象、桌面窗口对象和网络事件需要明确归属。

## 知识正文

### 浏览器与桌面的证据层

浏览器视图提供 DOM/无障碍树、页面控件、URL/标题和页面网络；Windows 桌面视图提供窗口/控件树与屏幕坐标；HTTP 视图提供请求响应；JS 运行时视图提供断点、函数值、CDP 与调用栈；签名或环境复现另需算法依赖证据。原文 Playwright、agent-browser、OpenReverse、anything-analyzer、jshookmcp、js-reverse 是这些能力的历史名称，不规定选择或连接。

### 页面生命周期与快照

当前 URL、标题、文档状态、完整无障碍树与可交互元素子集表达不同信息。原例的 @e1/@e2 是一次快照的元素引用，不是可跨刷新永久沿用的元素 ID。页面导航、刷新或重排后，引用可能不再对应原对象。

### 输入、点击与读取

点击、替换文本、逐字符输入、Enter 等按键、滚动、读取元素文本各有不同事件语义。页面脚本若监听输入过程，最终文本相同也不必然产生相同事件。滚动像素与屏幕位置是观察上下文，不是稳定业务身份。

### 等待与就绪

元素存在、固定时间已过、DOMContentLoaded 与 networkidle 是不同状态；源文在表单后以 networkidle 表达等待页面趋稳的经验，不保证后台行为已完成。浏览器会话未结束可能遗留进程或状态，生命周期证据应说明是否仍有会话，而不是要求执行特定关闭命令。

### 桌面 UIA 与 CUA

UIA 通过控件角色、名称、文本与树结构表达标准按钮、文本框和列表；CUA 通过屏幕、鼠标和键盘表达复杂/自绘界面。IDA 反汇编视图等非标准控件可能缺少可用结构树；截图中的坐标又受分辨率、DPI、窗口位置及布局影响。两类证据可互补，既不要求固定模式，也不把某个产品认定为必需。

### 网络观察模式

Proxy Lane 表示应用可配置代理时的代理视角；Local Lane 表示本地流量视角，原文用于无法走代理的应用。桌面交互是否包含网络证据是独立维度：仅 GUI、GUI+代理、GUI+本地流量分别提供不同范围；有网络视图不代表已经关联到目标进程或具体 GUI 事件。

### 逆向场景一：IDA 样本状态

目标二进制已加载、自动分析是否完成、函数列表是否可见/导出，以及 Lumina 等网络行为，是源案例承载的结果。批量样本的窗口与数据库身份需可区分；屏幕上“正在分析”与静态函数清单的完整性相关。本文不包含启动 IDA、加载、导出或网络连接调用。

### 逆向场景二：x64dbg 调试状态

目标程序身份、断点位置、运行/暂停、寄存器与内存变化、截图是原案例的证据对象。工具 UI 的按钮或快捷键是到达状态的历史方式，知识结论应描述实际状态与目标，不要求 agent 固定动作。

### 环境与历史名称

原文 OpenReverse 表示面向 GUI 与网络证据的框架，内含 UIA/CUA 与 mitmproxy 相关网络视角。原自举/手工安装章节承载的是浏览器引擎、结构化控件、视觉识别、网络可见性几类能力，本文保留其差异，移除下载、注册宿主、doctor、安装和部署说明。

## 观察与判断

URL 改变不单独证明登录成功；输入文本显示正确不证明事件监听已发生；截图坐标命中不证明控件身份正确；GUI 操作后出现流量不证明该流量来自目标动作。页面、控件、进程和网络之间需要对应证据。
