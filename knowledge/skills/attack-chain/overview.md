# 多阶段攻击链的结构与判断依据

来源：skills/attack-chain/SKILL.md

## 适用问题与编排原则

完整渗透评估、外部边界到域环境、攻防演练、攻击面分析、已有 Webshell 的影响评估、漏洞链式价值、持续漏洞研究、内网、近源、供应链和钓鱼后续场景，都涉及跨信任边界的关系。单一端口、SQL 输入或 APK 分析只涉及局部问题，无需人为扩成完整链。原文的 Skill 分发与代理总指挥机制改为领域知识之间的关联。

### 路径规划决策树

路径模型由目标类型（Web、内网、云、移动、IoT）、当前视角（外部、已有凭据、已有据点）、最终影响（域权限、数据、特定系统、证明影响）和约束（时间、可用性、不可触碰系统）组成。每条边需要前置能力、跨越的权限边界和可观察证据。失败结果表明某条边的前提不成立，可据此比较其他已知关系；它不自动证明目标整体安全。

## 一、信息收集：Reconnaissance

### 1.1 企业数字资产测绘

子公司、关联域、证书透明度、存活服务和端口共同形成资产关系。域名归并去重、HTTP 状态/标题/技术标签、端口与服务版本是原命令链的输出含义。企查查、天眼查、证书透明度是原文列出的公开信息类别。test、dev、staging 等测试环境及新系统可能与正式环境拥有不同边界。

### 1.2 敏感信息泄露狩猎

源码、环境配置、SQL 导出、管理入口、配置文件和前端 JavaScript 可能包含云 AK/SK、数据库连接、JWT 密钥、内部 API 文档和 VPN/堡垒机凭据。知识目标是确认泄漏位置、凭证角色、权限与有效期，并区分普通字符串与真实可复用凭证。搜索表达式和批量抓取代码已移除，实际值脱敏。

### 1.3 员工信息画像

部门架构、团队介绍、招聘技术栈和论文邮箱能暴露组织结构和标识规律。原文的姓名拼音/年份、首字母/部门、工号/域、姓名/常见后缀描述可预测账户或口令的成因；不保留可用于猜测的具体字典样例。观察结果是身份规则是否公开、是否与登录标识或弱口令策略相关。

### 1.4 技术栈指纹识别

HTTP 内容、头、资源、CMS 和框架特征形成技术假设。指纹输出应包含证据位置、版本置信度与可能的反向代理影响；单个标签不等于漏洞已存在。历史 whatweb、httpx、nuclei、wpscan 代表此类证据归纳。

## 二、边界突破：Initial Access

### 2.1 Web 漏洞与影响类别

| 类型 | 原文关联的影响 | 判断所需前提 |
|---|---|---|
| SQL 注入 | 数据暴露，数据库与系统边界扩大 | 输入进入查询、数据库权限与配置 |
| SSTI | 服务端模板执行语义 | 用户输入是否被当作模板 |
| 文件上传 | 服务端执行或危险内容落地 | 存储路径、解释器与内容验证 |
| 反序列化 | Java/PHP/Python 对象行为 | 不可信数据与可达类型/调用链 |
| SSRF | 内部网络或云身份暴露 | 出站能力、协议与元数据边界 |
| 未授权访问 | Actuator、Nacos、Redis 等暴露 | 访问控制和敏感操作实际可见性 |
| XSS 与会话 | 会话或高权限浏览器上下文影响 | 执行上下文与会话防护 |

这里保留漏洞与影响关系，原自动化调用及载荷不再出现。

### 2.2 供应链攻击

第三方组件或服务商、代码签名与更新权限、合法分发通道形成上游到下游信任传递。开源包投毒、SaaS API 权限、外包账号和共享 IT 服务商是原文入口类别。报告需要说明究竟哪个来源或发布权限失效，不能把使用第三方服务本身视为问题。

### 2.3 钓鱼攻击

源材料的邮件主题属于 VPN/IT/HR/财务的身份和紧急感诱导。宏文档、伪装快捷方式、HTML Smuggling、ISO/IMG 与 MOTW、OneNote 嵌入内容代表载体与执行边界，不保留诱导话术或制作过程。OAuth 钓鱼的核心是用户对恶意应用授予邮箱/文件等权限，授权可脱离密码流程；MFA 不自动撤销已授予的应用权限。原“2025 新趋势”是历史语境。

### 2.4 近源渗透：Physical Access

键盘注入设备、伪装数据线、伪造无线热点、RFID 克隆和网络植入分别关联 USB 信任、外围设备、无线身份、物理门禁和内部网络接入。原 Rubber Ducky、O.MG Cable、Fluxion、Proxmark3、Raspberry Pi 等名称保留为历史设备/概念，不规定设备或操作路径。观察结果应落到实际接入边界与告警。

### 2.5 VPN / 远程接入

Pulse Secure CVE-2019-11510、Fortinet CVE-2018-13379 在原材料中用于说明远程接入文件访问与会话泄漏的历史风险。密码喷洒反映跨账户尝试与身份锁定的聚合问题。本页保留漏洞标识、组件和影响，移除路径载荷及凭据尝试命令。

### 2.6 云服务

云资产与 CNAME、存储桶匿名访问、服务端取回与元数据、目录身份认证关联不同信任面。元数据中的临时身份需要结合 IAM 权限和生命周期理解；存储可列举与数据可读写不同。

## 三、权限提升：Privilege Escalation

### 3.1 Windows

SeImpersonate 与 Potato 系列属于令牌模拟边界；未修复内核缺陷属于系统版本边界；无引号服务路径、可写 DLL 搜索路径、AlwaysInstallElevated 和可写计划任务脚本属于高权限加载来源受低权限控制。证据包含令牌权限、服务/任务身份、路径可写性与实际加载目标。

### 3.2 Linux

SUID、sudo 允许程序的执行语义、可写脚本/配置和内核版本构成不同权限面。vim、find、python、nmap、less、awk、perl 在原文中表示具有额外执行能力的程序类别。DirtyPipe（CVE-2022-0847）与 DirtyCow（CVE-2016-5195）是历史内核例子；版本名不足以证明可受影响，仍涉及补丁和运行条件。提权命令已改为这些判断前提。

### 3.3 数据库

MSSQL 的 xp_cmdshell、MySQL UDF、PostgreSQL 的外部程序能力关联数据库身份到系统进程的边界。关键是相关功能是否启用、数据库主体权限、库文件来源和承载系统身份，不保留开启功能或执行系统命令的代码。

### 3.4 云权限

AWS 的 PassRole 与计算资源创建组合说明权限之间可能形成传递影响；Azure 的全局管理员、应用管理员和服务主体凭据关系说明目录角色与资源权限并非同一层。实际角色策略与资源范围是判断依据。

## 四、横向移动：Lateral Movement

### 4.1 凭据获取

Windows 登录内存、目录复制权限、Linux 账户数据库、shell 历史和配置文件是源材料列出的凭证承载位置。报告区分明文、哈希、票据和短期 token，标记可用范围及到期时间；原导出命令与真实值不保留。

### 4.2 Pass-the-Hash / Pass-the-Ticket

PTH 与 PTT 分别反映哈希和票据可被身份协议接受的条件。Kerberoasting 与 AS-REP Roasting 关联服务票据、预认证及离线口令强度；Golden Ticket 关联域关键签名材料与票据可信性。原示例的网段、域与密钥值均改为角色概念。

### 4.3 远程管理与隧道

WMI、DCOM、WinRM、PsExec、SSH SOCKS 和端口转发的差异是认证、远程进程、服务与网络转发痕迹。所谓无文件不等于无遥测；比较依据包括目标进程/服务、父子关系、网络连接与审计记录。

### 4.4 NTLM Relay

原文将名称解析/认证捕获、协议中继、被动接收与强制认证组合描述。知识核心是认证发起方、接收方和被认证资源之间的绑定是否充分，SMB/HTTP 等协议策略是否允许跨边界使用认证。报告保留协议角色与信任前提，不保留监听、强制认证或中继调用。

### 4.5 AD 攻击路径

目录图中的 GenericAll、WriteDacl、约束委派、DCSync 权限分别关联对象控制、ACL 修改、身份委派和复制敏感数据。AD CS 的证书模板把申请者权限、名称约束与认证用途联系起来。图中边需要实际 ACL、模板及认证证据支持，不由工具名称直接推出影响。

## 五、权限维持：Persistence

### 5.1 Windows

计划任务、Run 键、WMI 事件订阅、DLL 搜索、账户/RID 属性、Golden Ticket 和 DSRM 都是不同的长期状态承载点。原表的隐蔽程度是经验性比较；证据应关注触发条件、身份、持久对象和原始基线差异。WMI 的过滤器、WQL 事件和消费者绑定构成事件驱动关系，不复制创建脚本。

### 5.2 Linux

SSH authorized_keys、crontab、LD_PRELOAD、PAM 与 systemd 分别影响远程身份、定时任务、动态链接、认证模块和服务启动。原文中的关键知识是这些配置如何跨登录或重启保留影响；不保留写入后门、服务部署或通用口令代码。

### 5.3 云环境

定时计算任务、目录应用与新凭据、Graph API 权限、基础镜像污染是原文的持续身份/代码来源。观察项为触发器、应用权限、凭据生命周期和镜像继承范围。

## 六、EDR / AV：检测边界

### 6.1 核心监控面

静态签名、用户态 API、内核回调、内存、网络和日志各自看见不同证据。加密/混淆、间接 syscall、Unhooking、模块踩踏、堆加密、域前置、ETW 修改属于原文对抗概念，单一表面变化不能证明跨层遥测消失。

### 6.2 机制与观察项

自定义加载、系统调用来源、目标进程、HTTPS/中转、内存驻留和 LOLBins 关联文件特征、调用来源、模块完整性、网络目的地和进程行为。具体机制、失效条件和事件字段见本分工中的 EDR 知识模块；这里不形成组合执行顺序。

### 6.3 C2 框架的历史分类

Cobalt Strike 的团队协作、Sliver 的 Go/开源背景、Havoc 的模块化、Mythic 的跨平台 agent、AdaptixC2 的发行版收录背景，是原表的分类理由。保留为能力维度，不作为产品推荐、最新版本事实或部署依赖。

## 七、痕迹与反取证：Anti-Forensics

Windows Security/System/Application、Linux 认证/系统日志、shell 历史、文件时间戳、凭证内存转储、驻留组件和临时文件是源材料列出的痕迹。知识页把清除命令改为证据位置、缺口和残留解释；时间戳改变与日志缺失本身也有取证意义。

## 行动边界与失败经验

原三条底线表达授权范围、数据匿名化及环境恢复要求；原纪律中的时间/动作/结果日志、风险等级、业务可用性、高危影响及时沟通和真实用户数据最小化，保留为报告背景，不成为 agent 强执行协议。

未处理的凭证转储会暴露完整活动链；已被情报标记的 C2 域可能在首次连接即被阻断；钓鱼材料可能触发 DLP；横向活动可能命中蜜罐。它们分别说明内存/磁盘残留、基础设施信誉、邮件策略和诱捕环境会改变结论。源文的规避建议已转为这些失败原因与观察证据，没有扩展方法。

## 报告与领域关系

报告包含范围、当前身份与据点、目标影响、路径图、各边前提和证据、未成立路径、检测表现、恢复状态和剩余不确定性。Web、AD、移动、前端、二进制、浏览器与报告排版是相关知识领域；外部模块路径不确定处使用文字名称，无包外链接。
