# EDR / AV 检测面与对抗概念

来源：skills/attack-chain/references/evasion-cheatsheet.md

原材料汇总 2024–2026 年经验。以下保留技术机制和观察维度；历史检测难度和有效性判断不视作当前产品结论。

## 检测层与对应现象

| 检测层 | 防御方证据 | 原材料中的对抗概念与观察结果 |
|---|---|---|
| 静态签名 | 文件摘要、已知字节与结构 | 编译/加密/特征变化影响静态匹配，运行行为仍可能可见 |
| 用户态 Hook | ntdll 等 API 入口 | syscall、Unhooking、映像副本改变入口经过关系 |

| ETW | provider 与 session 事件 | 事件写入、启用状态或 provider 变化可能形成遥测缺口 |
| 行为分析 | 调用序列、时间与上下文 | 延迟、分散和业务相似性改变关联特征 |
| 内存扫描 | 映像、权限、驻留特征 | 堆/休眠加密、模块踩踏影响扫描时刻的内容 |
| 网络检测 | 出站目的地、协议与流量模式 | 域前置、中转和加密改变可见层，不消除连接证据 |

## 实用概念的原理与限制

### 1. 直接系统调用

用户代码直接进入系统调用边界，可能绕开用户态入口 Hook。SysWhispers3、Hell’s Gate、Tartarus Gate 是原文中的历史概念。原“绕过所有用户态 Hook”只描述入口路径，不能推导内核、调用栈或 ETW 不可见。

### 2. Unhooking

磁盘映像、KnownDlls 或挂起进程可作为映像对照来源；关注当前进程 `.text` 的入口跳转与可信基线差异。重新映射或恢复会改变页面和映像完整性并产生其他遥测，来源是否真的干净、版本是否匹配也是判断前提。

### 3. 进程注入与监控差异

源文把 RuntimeBroker、sihost、taskhostw、explorer 与 lsass、svchost、PowerShell/cmd 的关注程度作经验比较。名称只说明原观察背景，不形成目标选择建议。进程角色、访问句柄、跨进程写入、线程、映像及调用栈共同决定检测结论。

### 4. Module Stomping

已加载合法 DLL 的 `.text` 内容与磁盘映像不一致，说明映像身份与内存实际代码可能分离。模块标签合法并不能证明内容未变；判断重点是映像对照、节区权限和执行来源。

### 5. Sleep 加密

Ekko/Zilean 等概念描述休眠期与活动期内存内容不同，定时回调关联加密和恢复状态。瞬时扫描可能观察不到活动期特征，因此时间采样、权限转换和恢复一致性比单次扫描更有解释力。

### 6. Call Stack Spoofing

调用栈表象可以与实际控制流不一致。返回链、映像支持、展开元数据和真实线程行为的关系，才是基于调用栈检测的判断内容，原实现不在本页复制。

## C2 流量隐蔽的历史分类

域前置关联 HTTPS SNI 与 Host 的不同层；Cloudflare Workers 与 Azure/AWS 服务关联可信云基础设施中转；DoH 将 DNS 语义置于 HTTPS；WebSocket 表现为长连接；ICMP 隧道改变承载协议。原文依次标注高、高、极高、中、中、低检测难度，这些是经验判断，实际需要域名、网络策略、请求元数据和周期/大小证据。

## LOLBins：系统程序的双重用途

certutil 与 bitsadmin 在原例中承载下载；mshta 承载 HTA；rundll32 承载 DLL 入口；regsvr32 承载 SCT；wmic 承载远程进程；msiexec 承载 MSI；forfiles 承载间接命令执行。系统签名只能证明程序来源，不能证明参数、输入内容或行为目的。原命令、下载地址和载荷名称已转为这些输入输出关系。

## AMSI 与 PowerShell

原反射示例涉及 AmsiUtils 初始化状态、AmsiScanBuffer 和旧版 PowerShell 缺少 AMSI 的历史差异。初始化异常、接口错误或版本变化会影响扫描路径；修改过程可能被签名和行为检测识别。保留接口、状态与检测关系，不保留补丁代码或降级命令。

## 操作安全经验的知识化

动作规模与已有身份影响噪声和状态变化；工作/非工作时间影响人工审查环境；通信周期与大小影响异常检测；文件与内存生命周期影响残留；日志记录与缺失影响证据关联；异常开放服务、过于显眼的凭证可能属于诱捕；时间分散影响关联窗口。原七条 OpSec 规则转为这些观察变量，不给出规避、清理或固定执行要求。
