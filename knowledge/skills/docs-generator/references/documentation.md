# 通用技术文档

## README 结构

项目名称、一句话用途、适用对象、能力目录、输入输出、基本概念、条件与差异、完整参考、架构原理。读者应能从需求找到对应页，不必先读完所有功能。

## 接口说明结构

接口方法与资源路径、用途、身份上下文、参数、返回对象、分页与排序、状态码和业务错误。参数表使用名称、类型、必需性、默认值和语义；返回字段说明类型、含义和缺省行为。

| 状态 | 语义示例 | 需要解释的差异 |
| --- | --- | --- |
| 400 | 参数无效 | 哪个字段、校验规则和错误对象 |
| 401 | 身份缺失或无效 | 认证方式和生命周期 |
| 业务失败 | HTTP 层可能成功 | 业务码、状态对象与重试语义 |

示例展示抽象请求/返回结构即可；错误文档与正常路径同等可定位。

## 文档目录结构

总目录下面可以按 API、架构、指南、功能专题组织；API 下有认证、资源、错误；架构下有总览和数据流；指南下有问题定位；功能页按具体任务命名。

## 排版参考

短标题、适度分层、长页拆分、统一术语；表格比较多属性，图表表达关系，段落解释原因。代码或伪代码标明语言与上下文，文档描述与实际证据一致。
