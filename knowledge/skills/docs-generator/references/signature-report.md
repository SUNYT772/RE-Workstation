# JS / Web 签名分析报告

## 目标请求

记录方法、接口、参数来源、签名字段、身份状态和样本版本。用脱敏请求结构表达字段关系。

## 定位证据

描述从请求字段到生成位置的调用栈、数据流、异步边界、运行状态和代码位置。

## 算法还原

| 项目 | 内容 |
| --- | --- |
| 算法 | MD5、SHA、HMAC、AES 或自定义关系 |
| 规范化 | 键排序、原始顺序、大小写、空值、重复参数 |
| 序列化 | 编码、分隔符、URL 编码、JSON 空白与数字格式 |
| 参与字段 | 包含项、排除项、签名字段自身是否参与 |
| 状态依赖 | 时间戳单位、nonce、设备标识、会话、路径与方法 |
| 密钥来源 | 常量、会话返回、派生关系及生命周期，不暴露实际凭据 |

## 输入输出对照

以同一组原始字节比较目标输出与还原输出，记录大小写、字节长度和编码。逐项改变输入判断依赖，不把单次匹配当作全部路径成立。

## 差异解释

认证失败、签名错误、时间过期、环境指纹、频率限制和业务失败分别记录。HTTP 成功和业务成功分开判断。

## 遗留与材料

记录覆盖样本、未覆盖分支、版本差异、算法图与证据索引。
