# 逆向工程报告

## 结果摘要

说明分析目标、核心结论、证据范围与尚存疑点。

## 样本与对象

| 字段 | 记录内容 |
| --- | --- |
| 标识 | 文件名、版本、来源、样本编号 |
| 格式 | APK、ELF、PE、Mach-O 或其他 |
| 指纹 | 大小、架构、哈希、包名、入口 |
| 条件 | 影响结果的运行环境与样本差异 |

## 静态结构

记录编译器、保护机制、字符串、关键类和函数、调用关系、关键数据结构。算法部分描述类型、参数、模式、密钥来源与派生关系，关联到具体函数和位置。

## 运行行为

按观察点列出参数、返回值、线程与时序；区分静态推断与运行观察。描述网络、文件、注册表、进程行为，以及静态和动态证据是否一致。

## 发现与对照

每个结论对应样本位置、输入、预期现象、实际现象和反例。复核说明保留已知条件、依赖状态与原始结果摘要，便于独立核对。

## 遗留与附件

记录尚未覆盖的路径、证据缺口、替代解释、图表、截图说明与关联材料。
