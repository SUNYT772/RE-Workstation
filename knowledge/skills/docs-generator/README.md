## 写作方法

先呈现结论和读者要解决的问题，再逐层展开摘要、关键结果、完整参考与内部原理。章节标题以任务命名，例如“认证用户”，比只列类名更易定位。概念配具体输入输出或证据；条件、异常、版本差异放在相关结果附近。

简洁段落、清晰标题与结构化表格可以减少长墙文本。深层内容适合拆页；内部引用用相对链接。事实、推测、未知和下一步证据分开描述，未完成内容说明原因，真实凭据用脱敏标识。

图表可选用函数调用图、数据流、请求时序、状态机或路径图，参见 [图表知识](../diagram-generator/README.md)。报告文件名可按日期、类型、目标组织；使用当前任务已有的输出位置和排版也适用。
