# 无进展时的证据回溯

来源：skills/js-reverse/references/fallbacks.md

## 主题与范围

不同分析视角失去进展时，可回到哪些更直接的事实。

## 知识正文

| 无进展的位置 | 可重新核对的证据 |
|---|---|
| 断点定位 | 请求是否真实出现、是否选中正确请求 |
| 源码推测 | 运行时参数、返回值与调用栈 |
| Node 环境修正 | 页面实际读取的对象与依赖 |
| 深度去混淆 | 最小可复现链路是否成立 |

## 观察与判断

原文的回退顺序表达从复杂推断回到直接证据的经验；各分支不构成固定执行阶段。

## 记录与报告
