# 任务输入字段

来源：skills/js-reverse/references/task-input-template.md

## 主题与范围

描述前端逆向问题所需的信息结构。

## 知识正文

| 字段 | 记录内容 |
|---|---|
| 目标站点 | 站点标识 |
| 目标页面 | 产生目标行为的页面 |
| 目标请求 | 请求标识或稳定特征 |
| 关注参数 | 待解释的签名、密文或风控字段 |
| 已知线索 | 已有源码位置、运行时值或请求证据 |
| 期望产出 | 参数定位、算法解释或复现等目标 |
| 是否需要本地复现 | 是 / 否 |

## 观察与判断

本地复现是否属于产出，会影响需要保留的环境依赖证据；输入模板本身不规定执行动作。

## 记录与报告

未知项保持为未知，不将未验证线索写成事实。
