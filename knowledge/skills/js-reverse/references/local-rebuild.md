# 本地复现

来源：skills/js-reverse/references/local-rebuild.md

## 主题与范围

页面证据如何限定本地 JavaScript 复现范围。

## 知识正文

需解释的对象包括真实入口函数、调用顺序、参数来源和依赖的浏览器对象。环境依赖清单完整保留为：时间、随机数、storage、cookie、UA、canvas、crypto。

最小复现以目标入口及其必要依赖为边界；缺失项可根据页面读取证据逐步明确，不必将整套浏览器行为一次性模拟。

## 观察与判断

入口选错、顺序不符、参数来源遗漏和宿主对象行为不同都可能产生错误结果；代码能运行不等于目标参数已复现。

## 记录与报告

列出入口、依赖、参数来源、环境取值依据和页面/本地结果比较。
