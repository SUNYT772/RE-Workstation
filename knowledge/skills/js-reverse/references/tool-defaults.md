# 观察范围与定位参数

来源：skills/js-reverse/references/tool-defaults.md

## 主题与范围

原文默认参数体现的是缩小证据范围、控制输出量和建立稳定命中的经验。

## 知识正文

- 请求分页：初始页只代表当前窗口；目标不存在时需要考虑其他页，而非直接认定请求没有发生。
- 压缩源码：原文 excludeMinified=true 表示初始搜索排除压缩源码以减少噪声。该范围可能漏掉只存在于压缩脚本的实现，报告应明确搜索范围。
- 源码片段：局部片段适合定位；完整源码是后续复核与本地复现的材料，两者用途不同。
- URL 片段：请求触发条件应选能稳定识别目标请求的片段；过宽易误命中，过窄可能遗漏变动部分。
- 栈帧索引：frameIndex=0 是原文从当前栈顶了解暂停上下文的起点，不代表调用者一定无关。

## 观察与判断

分页、源码筛选和栈帧选择都会改变可见证据。未命中要结合范围解释，不能等同于逻辑不存在。
