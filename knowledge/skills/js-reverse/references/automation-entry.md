# 请求与源码观察入口

来源：skills/js-reverse/references/automation-entry.md

## 主题与范围

页面侧初始线索：目标页面、最近请求、调用来源、脚本范围和源码命中位置。

## 知识正文

| 观察对象 | 承载的技术信息 |
|---|---|
| 页面及导航状态 | 触发目标行为时的文档与页面上下文 |
| 最近网络请求 | 目标请求是否发生、请求的识别特征 |
| initiator | 请求发起位置和调用栈 |
| 已加载脚本 | 与该页面实际运行相关的源码集合 |
| 请求路径、参数名、函数名 | 在候选源码中缩小范围的搜索线索 |
| XHR/Fetch 或源码位置断点 | 请求边界与具体函数的运行时关联 |

## 观察与判断

这些对象形成页面、请求、栈、脚本、源码位置之间的证据关系，不要求固定调用顺序。未观测到 window、document、navigator 的具体读取行为时，环境模拟仍属于假设。

## 记录与报告

保留页面标识、目标请求特征、initiator、候选脚本及命中位置，并区分直接观察与源码推断。
