# Node 环境复现

来源：skills/js-reverse/references/node-env-rebuild.md

## 主题与范围

Node 与浏览器宿主环境之间的最小复现关系。

## 知识正文

复现材料由目标脚本、最小 shim 宿主对象和目标入口函数组成。原文的诊断链是：目标脚本与入口所需环境是否齐备，入口的首个异常或 first divergence 在何处，页面证据是否能解释该缺口。

shim 表达的是已观测的宿主契约，而不是任意填充的全局变量。首个异常和 first divergence 都需回到页面行为寻找依据。

## 观察与判断

程序没有抛错仍可能存在行为差异；参数结果与页面不一致时，记录首处分歧比无依据扩充模拟对象更有解释力。

## 记录与报告

记载脚本、入口、shim 的观测依据、首个异常/分歧和仍缺少的页面证据。
