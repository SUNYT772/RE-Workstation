# Shell APK 重建、对齐与签名产物

来源：skills/apk-reverse/scripts/rebuild-sign-install.sh

## 主题与范围

保留 Shell 原材料的产物状态与差异，移除运行调用、安装、自举、密钥及口令。

## 知识正文

### 产物与身份

工程目录、输出目录、基础名称、签名身份、目标设备共同定义材料。源默认输出在工程父目录，并以工程目录名派生 unsigned、aligned、signed 三类 APK。对应摘要字段是 unsigned_apk、aligned_apk、signed_apk、keystore 和涉及设备时的 install_device；这里只保留签名来源关系，不保留私密内容。

### 重建结果的分层

资源/smali 重建、4 字节归档对齐、签名、证书信息与验签、设备接受分别回答不同问题。源历史调试证书的 RSA 2048/10000 天是样例参数，不是要求；真实密钥、别名默认值、证书主体、口令和生成命令均不复制。

### 与 Windows 材料的语义差别

Shell 原材料中“覆盖”选项同时表达需要设备结果；Windows 材料则将两项分开。Shell 只在涉及设备结果时检查设备能力，Windows 在前面一并解析。两者都不能把“未涉及设备”写成“设备安装成功”。产物清理仅关系新旧文件可分辨性，知识页不提供删除操作。

## 观察与判断

工程缺失与重建失败不同；对齐、签名、验签各可独立失败；验签成功不证明发行身份或设备相容性。产物名称不能代替内容和状态验证。

## 记录与报告

记录输入工程、三个产物状态、对齐口径、签名身份及验证结论；涉及设备时说明设备身份和覆盖语义，注明与 Windows 版本的选项含义差别。
