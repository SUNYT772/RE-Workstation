# Windows 设备与进程观察上下文

来源：skills/apk-reverse/scripts/frida-run.ps1

## 主题与范围

设备枚举、进程身份、spawn/attach 与暂停状态的知识语义，不包含连接、注入或安装调用。

## 知识正文

### 设备与目标身份

原材料的设备条目包含 id、type、name；进程条目包含 pid、name。USB 与远端设备描述不同连接上下文，远端地址属于会话配置而非目标业务身份。原代码在 Package 与 Process 同时存在时选 Package；知识记录应明确最终目标究竟由包标识还是进程名称描述，避免歧义。

### 启动时机与暂停

spawn 表示覆盖新进程启动时机，attach 表示目标已经运行；初始化逻辑是否错过取决于该差别。Pause 与默认继续表达运行状态，影响事件是否已经发生以及何时采样。观察材料与目标脚本的关联需可追溯，但本文不保留加载参数。

### 缺失状态

无目标身份、无对应进程或缺失观察材料，是不同于设备不可见的状态；设备清单、进程清单与业务事件应分别记录。原文搜索 Python 可执行位置和自动安装的机制不属于领域知识依赖。

## 观察与判断

能看到设备不等于能看到目标进程，能看到进程也不等于观察到了初始化。源默认端口、本机路径和命令选项不作为技术判据。

## 记录与报告

记录设备 id/type/name、进程 pid/name、包/进程身份选择、spawn/attach 语义、暂停状态、观察时机及缺失范围。
