# Windows APK 解包材料的知识转写

来源：skills/apk-reverse/scripts/decode.ps1

## 主题与范围

保留双视图、路径命名、Manifest 解析、计数和局部失败含义；自动安装、命令拼装、删除输出等运行逻辑不复制。

## 知识正文

### 输入与产物分区

APK 身份、任务名、输出根、是否包含 Java 视图及是否包含资源/smali 视图共同界定产物。缺失 APK 与缺失某一分析视图是不同状态。原命名算法取不带扩展名的文件名，将 A–Z、a–z、0–9、点、下划线、连字符之外的字符替为下划线；空名用 apk。未指定输出根时，源材料采用 APK 父目录；任务下的 jadx 与 apktool 是两个历史产物分区名称。

### Manifest 读取

AndroidManifest.xml 的 package 是包身份来源。文件不存在、XML 不可解析或资源视图未包含时，源摘要可能为空；空值不表示 APK 没有包名。

### 摘要字段

| 字段 | 含义 |
|---|---|
| task_root | 当前材料的任务根 |
| jadx_out / apktool_out | Java 与资源/smali 视图位置 |
| package | XML 中的包名 |
| jadx_exit_code / apktool_exit_code | 两个视图各自的状态；未包含时可为空 |
| java_files | Java 视图内递归统计的 .java 文件数 |
| smali_dirs | 资源视图根下 smali* 目录数，不等于类或方法数 |
| so_files | 资源视图递归统计的 .so 文件数 |
| xml_files | 资源视图递归统计的 .xml 文件数 |

## 观察与判断

Java 视图非零退出码与“已有可读导出源码”可以同时存在；有效性需按具体文件判断。计数为零还可能因为视图未包含或产物缺失，不能直接认定对应内容不存在。不同任务的旧产物与当前产物混合会使计数失真。

## 记录与报告

记录 APK、任务身份、所含视图、两个视图状态、计数口径、解析失败和实际可用文件范围。源脚本的目录清理行为只保留为产物新旧需区分的知识，不提供删除动作。
