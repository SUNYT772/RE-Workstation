# Shell 设备与进程观察上下文

来源：skills/apk-reverse/scripts/frida-run.sh

## 主题与范围

保留设备、进程、目标和运行时机的区分，移除 CLI 参数、服务连接与注入代码。

## 知识正文

设备枚举描述可见设备的 id/type/name；进程视图描述所选设备中的进程。USB 与远端是观察上下文。包身份与进程名不是同一字段；源材料优先采用包身份，否则采用进程名称。

spawn 关注新启动进程的初始化窗口；attach 关注已存在进程；暂停状态影响目标是否继续运行。原摘要保留目标、观察材料、模式和连接上下文四类信息，足以帮助解释为何不同会话看到不同调用。

## 观察与判断

设备不可见、进程不存在、目标身份缺失、观察材料缺失各有不同含义。源设备清单存在两种取得方式，但二者技术目标相同；不能将后备路径成功等同于已取得业务证据。

## 记录与报告

记录设备与进程身份、目标选取依据、spawn/attach、暂停状态和观察窗口，不复制固定远端地址或任何调用。
