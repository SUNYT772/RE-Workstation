# 二进制静态分析与数据库知识

本模块保留原 IDA 分析材料的知识内容，适用于 PE、ELF、Mach-O、EXE、DLL、SO、SYS、固件及其他二进制的结构理解、反编译、漏洞定位与行为解释。IDA、Hex-Rays、FLIRT、Lumina 与 MCP 在文中是历史实现或格式背景，不构成工具依赖。

## 阅读导航

| 知识页 | 内容 | 适用问题 |
| --- | --- | --- |
| [分析框架与故障经验](overview.md) | 样本概况、函数与数据流、数据库状态、锁文件、长时间分析、报告 | 如何组织发现、判断“卡住”及解释证据 |
| [分析对象与观察字段](references/ida-mcp-cheatsheet.md) | 查询维度、交叉引用、内存、类型、栈帧、签名、补丁记录、导出格式 | 某个分析结论需要哪些字段、如何核对 |

## 内容组织

入口只说明范围与导航；完整原理、观察项和故障定位位于各知识页。相关领域包括动态行为验证、符号执行和通用逆向方法；其目录由工作站上级导航维护。
