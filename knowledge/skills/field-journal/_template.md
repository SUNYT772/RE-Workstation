# 经验材料的知识记录结构

来源：skills/field-journal/_template.md

## 来源性质与用途

本页是模板结构说明，不是已完成项目。真实项目、公开研究整理与 [种子] 预置素材分别标记，日期、环境和证据属于原材料，不能用模板字段暗示已经执行或验证。

## 场景分类与目标概述

原分类包括 APK 逆向、JS 签名、二进制、渗透、CTF、协议/抓包与其他。目标概述交代对象类型、实际问题、输入材料和期望解释的机制；主机、真实目标和账户使用角色标识。

## 完整观察与决策

材料可按输入、观察、假设、判断依据、结果与反例组织。先后关系服务于解释因果，而非规定 agent 阶段。原链路中的弯路、无结果和不成立路径与成功结果同等保留；“文档已读”“尝试发生”“有结果”“已验证”是不同状态。

## 失败路径与诊断表

| 字段 | 实质内容 |
|---|---|
| 问题 | 错误、响应、崩溃、缺失状态等实际现象 |
| 原因 | 证据支持的根因，或明确标识的候选原因 |
| 决策/修复 | 原方案承载的技术目标和前提，避免命令或强执行要求 |
| 验证 | 修复前后差异、负向结果和未覆盖范围 |
| 耗时 | 原记录中的数值或“未记录”，不补造 |

## 能力与格式知识

原工具链字段转为能力、输入/输出、格式、版本兼容与局限。工具名可作历史名，不要求安装或调用；路径和状态需与原环境对应，旧版本经验不自动推广。

## 技术机制、算法与证据

协议字段、结构、算法、寄存器/ABI、数据流、校验与判断阈值在相关页实质保存。源纯算法可写为知识伪代码；原 hook、载荷、部署和命令改为技术目标、可观察结果和失效条件。证据可以是脱敏请求结构、字段变化、日志/截图说明、反汇编语义与报告事实，不依赖可复制执行代码。

## 可迁移经验与材料改进

经验表达为适用条件、判断依据、反例和限制；相邻知识缺少的具体主题可以注明，但不规定新增技能、注册路由、维护工具清单或运行安装器。原平台进化勾选表已转为来源维护说明。

## 环境信息

保留原 OS、架构、运行库、软件版本、协议与配置前提。标准组件路径可解释机制，个人安装/日志路径替换为角色。没有原记录的字段以未记录表达，不能拿通用环境填充。

## 脱敏与索引知识

[脱敏知识页](anonymization.md)说明角色、结构和证据的保留边界。目标域/IP、业务标识、token、Cookie、JWT、OAuth code 与 API key 均角色化，协议与字段、CVE 和技术格式保留。索引表达场景、日期、关键词、来源性质和对应知识页；统计需按实际材料口径，模板和规范页不计为真实项目。本页不含索引同步或提交的强执行协议。
