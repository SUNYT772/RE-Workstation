# 知识编排参考

知识可以按独立对象、问题或结果类型分模块；已有模块的子主题适合留在对应参考页。入口概括适用问题，目录指向细分方法，参考页保留识别信号、原理、条件、判断、证据与经验。

## 模块结构

- 一页入口：说明能回答什么问题、有哪些知识页、与其他模块的关系。
- 细分参考：各技术主题独立成页，保留原理和细节。
- 经验记录：案例条件、关键观察、有效与无效方向、可迁移结论。
- 结果模板：输入输出、字段含义、证据与报告排版。

## 检索与关联

可按对象类型、用户问题、可观察证据建立多个入口；这些是知识视角，不限制 agent 的执行方式。新页可在原能力目录下加入链接；跨域知识可以互相关联。

## 内容维护

技术事实标注出处、适用版本与不确定性。个人路径、凭据、运行状态与一般知识分开。历史命令承载的分析思想可以转成原理和观测结构；工具部署与具体 agent 控制协议不属于本版知识编排。
